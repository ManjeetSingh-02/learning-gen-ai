# Coding Preferences
Coding preferences are a set of guidelines and choices that developers make regarding the programming languages, frameworks, libraries, and tools they use for software development. These preferences can vary based on personal experience, project requirements, team standards, and industry trends.

## Languages
- Languages user is most comfortable with or prefer to use for development.
- The detailed information about preferred languages are stored in `references/languages` folder.

## Frameworks
- Frameworks user prefer to work with for building applications, whether they are web, mobile, or desktop applications.
- The detailed information about preferred frameworks are stored in `references/frameworks` folder.

## Tools
- Development tools, IDEs, and other software that user prefer to use for coding, debugging, and testing.
- The detailed information about preferred tools are stored in `references/tools` folder.

## Additional Information
- Refer to the `assets/preferences-output.json` for a structured output.
